# Any Gym Coach site

This repository holds the support page and the privacy policy page for the Any Gym Coach iPhone app.

- `index.html` is the support page.
- `privacy.html` is the privacy policy page.
- `styles.css` is the only stylesheet.

GitHub Pages serves the site from the root of the `main` branch. The `.nojekyll` file tells Pages to serve the files as they are.

The site is static. It has no build step, no framework, no analytics, no external scripts, no third-party fonts and no cookies. Each page sets a Content Security Policy that blocks every resource that is not on this site.

The page text is placeholder text for now. The final text replaces it after review.
